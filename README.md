Die gesamte Projektdokumentation liegt in [`Docs/`](Docs/). Einstieg: [`Docs/PROJECT_MASTER.md`](Docs/PROJECT_MASTER.md), danach `ARCHITECTURE.md`, `INTEGRATION.md`, `SYSTEM_INTERFACES.md`, `CURRENT_STATE.md`.
